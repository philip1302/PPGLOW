PPGlow-Hilfe

TPPGDarkColors

Typ in Unit PPG.Appearance - Basis TPersistent

Eigene Farben fuer den Dark Mode (sonst gelten dort die Preset-Farben).

Eigene Farben im Dark Mode, je Zustand als TPPGStateColors. Gesetzte Werte gelten nur im Dunkeln.

Eigenschaften

EigenschaftTypVorgabeWirkung und Nutzung
NormalTPPGStateColorsRuhezustand im Dunkeln. Praxis: Ruhe-Optik im Dark Mode für selbst eingefärbte Buttons, z. B. ein dunkleres Rot für „Löschen".
HotTPPGStateColorsMaus darüber im Dunkeln. Praxis: Hover-Optik im Dark Mode; meist etwas heller als Dark.Normal.
DownTPPGStateColorsGedrückt im Dunkeln. Praxis: Gedrückt-Optik im Dark Mode.
DisabledTPPGStateColorsDeaktiviert im Dunkeln. Praxis: Gesperrt-Optik im Dark Mode.
CheckedTPPGStateColors„An"-Zustand (CheckBox, Radio, Schalter) im Dunkeln. Praxis: Eingerastet-Optik im Dark Mode.
FocusedTPPGStateColorsFokus-Farben im Dunkeln. Praxis: Fokus-Optik im Dark Mode.
FocusColorTColorclDefaultFokusring im Dunkeln; clDefault = wie im Hellen bzw. Preset. Praxis: Farbe des Fokusrings im Dark Mode; hell wählen, damit er auf dunklem Grund sichtbar ist.
