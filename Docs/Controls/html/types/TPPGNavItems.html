TPPGNavItems

Typ in Unit PPG.NavigationView - Basis TOwnedCollection

Die Einträge der Navigationsleiste (Collection), auch mit Untereinträgen (Children), Überschriften und Fußbereich.

Nutzung: PPGNavigationView1.Items.AddItem('Start', $E80F);

Collection: Die Eintraege sind vom Typ TPPGNavItem. Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber Add, Items[i], Count, Delete, Clear.

Verwendet in

TPPGNavigationView, TPPGNavItem
