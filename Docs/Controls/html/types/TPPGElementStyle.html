PPGlow-Hilfe

TPPGElementStyle

Typ in Unit PPG.ElementStyle - Basis TPersistent

Aussehen eines Bereichs (z. B. Kopfzeile, Auswahl, Zebra-Zeile). clDefault heißt „vom Preset berechnet": Ein leerer Stil ändert nichts und wird nicht in der DFM gespeichert. Farben gelten nicht im Hochkontrast und nicht mit VCL-Style, Schriften immer.

Nutzung: Grid.Styles.Header.Color := clNavy; Grid.Styles.Header.TextColor := clWhite; Grid.Styles.Header.FontStyle := [fsBold];

Eigenschaften

EigenschaftTypVorgabeWirkung und Nutzung
ColorTColorclDefaultFlächenfarbe des Bereichs im Hellen; clDefault = vom Preset. Praxis: Eigene Flächenfarbe für den Bereich, z. B. ein helles Grau für gesperrte (ReadOnly) Felder. clDefault lassen, wenn das Preset passt.
TextColorTColorclDefaultTextfarbe im Hellen; clDefault = vom Preset. Praxis: Eigene Textfarbe, z. B. clGrayText für schreibgeschützte Felder; auf ausreichenden Kontrast achten.
BorderColorTColorclDefaultRand- bzw. Linienfarbe im Hellen; clDefault = vom Preset. Praxis: Eigene Randfarbe, z. B. ein blasser Rand, damit ein gesperrtes Feld zurücktritt.
DarkColorTColorclDefaultFlächenfarbe im Dark Mode; clDefault = vom Preset (eigene helle Farben gelten im Dunkeln nicht). Praxis: Gegenstück zu Color für den Dark Mode. Setzen, sobald Sie Color selbst gesetzt haben, sonst bleibt die Fläche im Dunkeln hell.
DarkTextColorTColorclDefaultTextfarbe im Dark Mode; clDefault = vom Preset. Praxis: Gegenstück zu TextColor für den Dark Mode; hell wählen, damit der Text auf dunklem Grund lesbar ist.
DarkBorderColorTColorclDefaultRand- bzw. Linienfarbe im Dark Mode; clDefault = vom Preset. Praxis: Gegenstück zu BorderColor für den Dark Mode.
ParentFontBooleanTrueTrue: Schrift des Controls; wird False, sobald Font geändert wird. Praxis: True lassen, damit der Bereich die Schrift des Controls nutzt. Eine eigene Schrift (Font) setzt es automatisch auf False.
FontTFontEigene Schrift des Bereichs (wirkt nur mit ParentFont = False). Nutzung: Grid.Styles.Footer.Font.Size := 8; Praxis: Nur für eine abweichende Schrift des Bereichs, z. B. kursiv für schreibgeschützte Werte. Für fett reicht FontStyle.
FontStyleTFontStyles[]Zusätzliche Schriftstile auf die Schrift des Controls bzw. auf Font (z. B. [fsBold] für eine fette Kopfzeile ohne eigene Schrift). Praxis: Einfacher als eine eigene Font: [fsBold] für eine hervorgehobene Kopfzeile oder [fsItalic] für gesperrte Werte.
