TPPGAnimationSettings

Typ in Unit PPG.Animation - Basis TPersistent

Steuert die Übergangsanimationen eines Controls (Hover, Drücken, Fokus, Aufklappen).

Eigenschaften

EigenschaftTypVorgabeWirkung und Nutzung
EnabledBooleanTrueFalse: Zustandswechsel ohne Überblendung.
DurationIntegerPPGDefaultAnimationDurationDauer einer Überblendung in Millisekunden (Standard 150).
RespectSystemSettingsBooleanTrueTrue: Ist in Windows „Animationen anzeigen" aus, wird nicht animiert.
