PPGlow-Hilfe

TPPGCheckListBox

Palette PPGlow - Unit PPG.CheckListBox - Basis TPPGCustomCheckListBox

Vorbild: TCheckListBox

Unterschiede und Hinweise

  • Kästchen im Preset-Stil; Header[] macht Zeilen zu Überschriften (ohne Kästchen, nicht wählbar).
  • Checked[]/State[] im Code lösen kein Ereignis aus; der Anwender löst OnClickCheck aus.
  • UI Automation: zusätzlich Toggle-Muster je Eintrag.

Verhalten (aus dem Quelltext)

TPPGCheckListBox - ListBox mit Kaestchen, DFM-kompatibel zu TCheckListBox.

Die Kaestchen zeichnet IPPGIndicatorRenderer des Presets (wie TPPGCheckBox). Zustand pro Zeile: bei Items in der Huelle der Zeile (wandert beim Sortieren/Verschieben mit), bei ItemsEx in TPPGItem.Checked, virtuell ueber OnGetItem (Data.Checked) und OnSetChecked.

Bedienung wie TCheckListBox: Klick auf das Kaestchen oder Leertaste schaltet um (aus -> an -> gemischt, wenn AllowGrayed), danach OnClickCheck. Setzen im Code (Checked[], State[], CheckAll) loest kein Ereignis aus. Header[] macht eine Zeile zur Ueberschrift (ohne Kaestchen, nicht waehlbar).
