PPGlow-Hilfe

TPPGDBMaskEdit

Palette PPGlow DB - Unit PPG.DB.Fields - Basis TPPGMaskEdit

Vorbild: DB-Variante von TPPGMaskEdit (wie TDBEdit)

Unterschiede und Hinweise

  • Bindet sich über DataSource/DataField an ein Feld. Die Anbindung ist für alle Phase-12-Felder dieselbe (TPPGDBValueBinding, Schnittstelle IPPGFieldValue).
  • Null im Feld wird zum leeren Control, und ein leeres Control schreibt Null.
  • Tippen bzw. Auswählen setzt den Datensatz in Bearbeitung. Ist das nicht möglich, kommt der Feldwert zurück.
  • Beim Verlassen und bei einem Post (auch über einen Navigator) wird geschrieben. Eine laufende Eingabe wird vorher übernommen.
  • Fehler stehen am Feld (ValidationState), es erscheint kein Dialog.
  • Esc setzt die Bearbeitung zurück.

Verhalten (aus dem Quelltext)

DB-Varianten der Eingabefelder aus Phase 12 (12g): TPPGDBMaskEdit, TPPGDBNumberEdit, TPPGDBColorPicker, TPPGDBCheckComboBox, TPPGDBTagEdit.

Alle binden sich ueber IPPGFieldValue (PPG.Controls.Field) an das Feld - eine Anbindung (TPPGDBValueBinding) statt einer je Feldtyp:

  • Datensatz wechselt: Null -> FieldClear, sonst SetFieldValue (still, ohne OnChange). Text-Modus (Maske, Auswahl, Tags) ueber Field.Text, sonst Field.Value (Zahl, Farbe).
  • Anwender aendert: Datensatz in den Bearbeiten-Modus (EditByUser), dann Modified; geht das nicht, wird der Feldwert wieder angezeigt.
  • Schreiben (UpdateData, auch beim Post ueber einen Navigator): eine laufende Eingabe wird vorher uebernommen (Zahl rechnen, Tag anlegen).
  • Verlassen: UpdateRecord; ein Fehler steht am Feld (ValidationState), kein Dialog (PPGDBCommitField aus Phase 9).
  • TPPGDBMaskEdit uebernimmt Field.EditMask, wenn es keine eigene Maske hat.
  • TPPGDBNumberEdit: AllowNull ist Vorgabe (Null ist nicht 0).
  • Auswahl und Tags speichern als getrennten Text (Delimiter).

Nutzung: PPGButton1.Appearance.Normal.Color := $00F0E0D0; PPGButton1.Appearance.Rounding := 8; Praxis: Selten je Feld ändern. Die Fehler- und Warnfarben kommen aus ValidationState; Rand und Rundung besser zentral über Preset oder StyleManager.

Praxis: An lassen: Der Wechsel von Rand und Fokus wirkt ruhiger. RespectSystemSettings beachtet die Windows-Einstellung „Animationen anzeigen".

Nützlich, solange EditMask leer ist, oder als Hinweis auf das Format („TT.MM.JJJJ") neben einer Maske mit Leerzeichen als Leer-Symbol.

Praxis: True, wenn der Platzhalter beim Hineinklicken noch als Formatvorgabe sichtbar bleiben soll; bei Maskenfeldern meist ohne Wirkung, weil die Maske ihre Platzhalter ohnehin zeigt.
UseSystemContextMenuBooleanFalseTrue: Rechtsklick zeigt das native Windows-Menü des Edits statt des PPGlow-Menüs (Rückgängig, Ausschneiden, Kopieren, Einfügen, Löschen, Alles markieren; übersetzt und im Preset-Stil). Praxis: False lassen, dann passt das Kontextmenü zur PPGlow-Optik und Sprache. True nur, wenn Anwender exakt das Windows-Menü erwarten (z. B. Unicode-Steuerzeichen einfügen).

Nutzung: if not IstMail(Edit1.Text) then begin Edit1.ValidationState := pvsError; Edit1.ValidationHint := 'Keine gültige Adresse'; end; Praxis: Die Maske setzt pvsError selbst, wenn das Feld unvollständig verlassen wird. HighContrastSupportBooleanTrueTrue: Im Windows-Hochkontrastmodus verwendet das Control die Systemfarben statt der eigenen Farben (empfohlen für Barrierefreiheit). Praxis: True lassen, damit sehbehinderte Anwender im Hochkontrast klare Systemfarben sehen.
ShowClearButtonBooleanFalseTrue: Ein „×"-Knopf im Feld löscht den Text (nur sichtbar, wenn Text vorhanden und das Feld bearbeitbar ist). Praxis: Für optionale Felder, die man schnell wieder leeren will, z. B. eine freiwillige IBAN. Bei Pflichtfeldern weglassen, ein leeres Feld ist dort ohnehin ein Fehler.
AlignmentTAlignmenttaLeftJustifyAusrichtung des Textes im Feld (links, rechts, zentriert). Praxis: taCenter für kurze, gleich lange Werte wie Uhrzeiten in einer Zeile, taRightJustify für Beträge oder Nummern in Spalten; sonst taLeftJustify.
AutoSelectBooleanTrueTrue: Beim Fokus per Tab wird der ganze Text markiert. Praxis: True lassen: Wer per Tab in ein Datum springt, überschreibt es sofort komplett. False, wenn meist nur einzelne Stellen korrigiert werden.
BorderStyleTBorderStylebsSinglebsSingle: Rahmen nach Appearance; bsNone: ohne Rahmen (z. B. eingebettet in eigene Flächen). Praxis: bsSingle für normale Formularfelder. bsNone nur, wenn das Feld in eine eigene Fläche eingebettet ist, z. B. als Zelleneditor in einer Liste.
CharCaseTEditCharCaseecNormalErzwingt Groß- oder Kleinschreibung der Eingabe (ecNormal, ecUpperCase, ecLowerCase). Praxis: Bei Masken lieber die Zeichen „>" (groß) und „<" (klein) in EditMask verwenden, die gelten je Abschnitt. CharCase = ecUpperCase passt für Felder ohne Maske, z. B. Kennzeichen oder Kürzel.
EditMaskstringEingabemaske wie bei TMaskEdit (z. B. „00000;1;_" für eine PLZ oder „!99/99/0000;1;_" für ein Datum): Platzhalter, ob Literale gespeichert werden, und das Leerzeichen-Symbol. Nutzung: MaskEdit1.EditMask := '+49 999 99999999;0;_'; Praxis: Für Werte mit festem Aufbau: PLZ „00000;0;_", Datum „00.00.0000;1;_", Uhrzeit „00:00;1;_", Kundennummer „KD-000000;1;_". Als zweite Stelle 1 nehmen, wenn die festen Zeichen (Punkte, Bindestriche) zum gespeicherten Wert gehören; bei Masken ohne feste Zeichen wie der PLZ ist sie egal.
HideSelectionBooleanTrueTrue: Die Markierung wird ausgeblendet, wenn das Feld den Fokus verliert. Praxis: True lassen. False nur, wenn ein Button daneben mit der Markierung arbeitet (z. B. „Markierte Stellen löschen") und sie sichtbar bleiben soll.
MaxLengthInteger0Höchstzahl der Zeichen; 0 = unbegrenzt. Praxis: Mit Maske selten nötig, die Maske begrenzt die Länge schon. Ohne Maske z. B. MaxLength = 20 passend zur Datenbankspalte.
PasswordCharChar#0Zeichen, das statt der Eingabe angezeigt wird; #0 = Klartext. Praxis: Für vertrauliche Werte mit festem Aufbau, z. B. eine PIN „0000;0;_" mit PasswordChar = „*". Für Kennwörter besser TPPGPasswordEdit (Auge zum Aufdecken, Feststelltaste-Hinweis).
ReadOnlyStyleTPPGElementStyleEigene Optik bei ReadOnly: Fläche, Text- und Randfarbe (je auch für Dunkel). clDefault = wie im bearbeitbaren Zustand. ReadOnlyStyle.Color = $00F3F3F3 (hellgrau). clDefault lassen, wenn die Optik des Presets reicht.
TabStopBooleanTrueTrue: Das Feld ist mit Tab erreichbar. Praxis: True lassen, Eingabefelder müssen per Tab erreichbar sein. False nur bei ReadOnly-Feldern, die man beim Erfassen überspringen soll.

OnMouseUpTMouseEvent (Sender: TObject; Button: TMouseButton; Shift: TShiftState; X, Y: Integer)Maustaste über dem Control losgelassen. Praxis: Selten für Eingabefelder; Gegenstück zu OnMouseDown.
OnValidationErrorTNotifyEvent (Sender: TObject)Beim Verlassen passt die Eingabe nicht zur Maske. Statt des VCL-Fehlerdialogs wird ValidationState = pvsError gesetzt; hier kann man zusätzlich reagieren. Ein ganz leeres Feld gilt als gültig. Praxis: Für Reaktionen auf eine unvollständige Eingabe über das Rot hinaus: Meldung in der Statuszeile („PLZ unvollständig ab Stelle 4", siehe InvalidPos) oder den Speichern-Button sperren. Ersetzt den Fehlerdialog des TMaskEdit, den Anwender als störend empfinden.
OnMouseWheelTMouseWheelEvent (Sender: TObject; Shift: TShiftState; WheelDelta: Integer; MousePos: TPoint; var Handled: Boolean)Mausrad gedreht; Handled := True verhindert das Standard-Scrollen. Praxis: Z. B. in einem Uhrzeitfeld: Rad dreht die Minuten weiter. Handled := True verhindert dann das Scrollen des Formulars.
OnMouseActivateTMouseActivateEvent (Sender: TObject; Button: TMouseButton; Shift: TShiftState; X, Y, HitTest: Integer; var MouseActivate: TMouseActivate)Mausklick auf ein noch inaktives Fenster; legt fest, ob es aktiviert wird. Praxis: Nur in Spezialfällen (Werkzeugfenster) belegen.
OnDragDropTDragDropEvent (Sender, Source: TObject; X, Y: Integer)Ein gezogenes Objekt wurde über dem Control losgelassen. Nutzung: Source ist das gezogene Control; X, Y die Position im Control. Praxis: Wenn ein Wert aus einer Liste ins Feld gezogen werden darf, z. B. eine Kundennummer: hier Text setzen.
OnDragOverTDragOverEvent (Sender, Source: TObject; X, Y: Integer; State: TDragState; var Accept: Boolean)Ein Objekt wird über dem Control gezogen; Accept := True erlaubt das Ablegen. Praxis: Zusammen mit OnDragDrop: Accept := True nur für passende Quellen.
OnStartDragTStartDragEvent (Sender: TObject; var DragObject: TDragObject)Beginn des Ziehens dieses Controls; hier kann ein eigenes DragObject gesetzt werden. Praxis: Nur bei DragMode = dmAutomatic: eigenes DragObject beim Ziehen des Felds setzen.
OnEndDragTEndDragEvent (Sender, Target: TObject; X, Y: Integer)Ziehen dieses Controls beendet (abgelegt oder abgebrochen; Target = nil bei Abbruch). Praxis: Nach dem Ziehen des Felds selbst; bei Eingabefeldern kaum gebraucht.
