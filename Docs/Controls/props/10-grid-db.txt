# --- TPPGCheckComboBox ---
TPPGCheckComboBox.CheckedText = Die angehakten Einträge als ein Text, getrennt durch Delimiter (z. B. „Rot;Grün"). So wird die Auswahl in der DFM gespeichert und an DB-Felder gebunden. Setzen aus Code hakt die passenden Einträge an, ohne OnChange oder OnItemCheck auszulösen.
> `PPGCheckComboBox1.CheckedText := 'Montag;Mittwoch';`
TPPGCheckComboBox.Delimiter = Trennzeichen in CheckedText (und damit im DB-Feld). Vorgabe „;".
TPPGCheckComboBox.DisplayDelimiter = Trenner zwischen den Namen in der Anzeige des Felds (Vorgabe „, "). Betrifft nur die Anzeige, nicht CheckedText.
TPPGCheckComboBox.DisplayMode = Anzeige der Auswahl im geschlossenen Feld: cdmCompact zeigt die ersten MaxDisplayItems Namen und „+n", cdmList alle Namen, cdmCount nur „3 ausgewählt". Ohne Auswahl erscheint TextHint.
TPPGCheckComboBox.DropDownCount = Sichtbare Zeilen der Aufklappliste, danach wird gescrollt (1..100).
TPPGCheckComboBox.FilterThreshold = Ab dieser Zahl von Einträgen erscheint oben in der Liste eine Filterzeile; getippte Zeichen filtern die Einträge. 0 = nie.
TPPGCheckComboBox.Items = Die auswählbaren Einträge, je Zeile einer. Den Haken je Eintrag liest und setzt man über Checked[Index].
> `PPGCheckComboBox1.Items.CommaText := 'Rot,Grün,Blau'; PPGCheckComboBox1.Checked[1] := True;`
TPPGCheckComboBox.MaxDisplayItems = Bei DisplayMode = cdmCompact: so viele Namen werden ausgeschrieben, der Rest als „+n" (1..100).
TPPGCheckComboBox.OnItemCheck = Der Anwender hat einen Eintrag an- oder abgehakt (auch über „Alle auswählen"); Index ist der Eintrag in Items. Danach folgt OnChange. Änderungen aus Code lösen es nicht aus.
> `procedure TForm1.CheckItem(Sender: TObject; Index: Integer); begin Log(Items[Index]); end;`
TPPGCheckComboBox.ShowSelectAll = True: Erste Zeile der Liste ist „Alle auswählen" zum An- und Abhaken aller Einträge.

# --- TPPGColorPicker ---
TPPGColorPicker.DefaultColorColor = Farbe, mit der das Feld „Standard" (Selected = clDefault, mit cbIncludeDefault im Style) dargestellt wird.
TPPGColorPicker.MaxRecent = Wie viele zuletzt benutzte Farben gemerkt und als eigener Abschnitt gezeigt werden (0..32; 0 = kein Abschnitt).
TPPGColorPicker.NoneColorColor = Füllung des Farbfelds für „Keine“ (clNone) im Feld und im Popup, wie TColorBox.NoneColorColor. Die Vorgabe clBlack zeigt das Feld leer mit roter Diagonale (Preset-Optik); jede andere Farbe füllt es (die Diagonale bleibt).
> `ColorPicker1.NoneColorColor := clWhite;`
TPPGColorPicker.RecentColors = Zuletzt benutzte Farben als Hexwerte „#RRGGBB", die neueste zuerst. Wird beim Wählen automatisch fortgeschrieben und in der DFM gespeichert; kann zum Speichern in einer Einstellung gelesen und wieder gesetzt werden.
> `Ini.WriteString('Farben', 'Zuletzt', PPGColorPicker1.RecentColors.CommaText);`
TPPGColorPicker.Selected = Die gewählte Farbe. clNone = „Keine", clDefault = „Standard". Setzen aus Code löst kein OnChange aus.
> `Panel1.Color := PPGColorPicker1.Selected;`
TPPGColorPicker.ShowHex = True: Das Feld zeigt den Hexwert („#1E90FF") statt des Farbnamens.
TPPGColorPicker.ShowThemeColors = True: Das Popup zeigt oben die Designfarben des Presets (Akzent, Signalfarben, Diagrammpalette), damit gewählte Farben zum Theme passen.
TPPGColorPicker.Style = Abschnitte des Popups wie bei TColorBox: cbStandardColors (16 Grundfarben), cbExtendedColors (weitere Farben), cbSystemColors (clBtnFace usw.), cbIncludeNone („Keine"), cbIncludeDefault („Standard"), cbCustomColor (Schaltfläche „Weitere Farben …" mit HSV-Feld und Hex-Eingabe), cbPrettyNames (lesbare Namen).
> `PPGColorPicker1.Style := [cbStandardColors, cbIncludeNone, cbCustomColor];`

# --- TPPGCustomComboBox (ComboBox, DB-ComboBox, Lookup, SearchEdit, TimePicker) ---
TPPGCustomComboBox.AutoCloseUp = True: Springt die Tippsuche bei offener Liste auf einen Eintrag, wird er sofort übernommen und die Liste geschlossen.
TPPGCustomComboBox.AutoComplete = True: Bei Style = csDropDown ergänzt das Feld den getippten Anfang zum ersten passenden Eintrag (der Rest ist markiert und wird beim Weitertippen ersetzt).
TPPGCustomComboBox.AutoDropDown = True: Die Liste klappt beim Tippen automatisch auf.
TPPGCustomComboBox.AutoDropDownWidth = True: Die Liste wird so breit wie der längste Eintrag, mindestens so breit wie das Feld bzw. DropDownWidth (wie TComboBox.AutoDropDownWidth).
TPPGCustomComboBox.DropDownCount = Sichtbare Zeilen der Aufklappliste, danach wird gescrollt (mindestens 1).
TPPGCustomComboBox.DropDownWidth = Breite der Aufklappliste in logischen Pixeln; 0 = so breit wie das Feld. Nützlich für lange Einträge in schmalen Feldern.
TPPGCustomComboBox.FilterMode = Filtern beim Tippen (nur Style = csDropDown): fmNone zeigt immer alle Einträge, fmPrefix nur die mit diesem Anfang, fmContains alle, die den Text irgendwo enthalten. Die Liste klappt dabei auf.
> Für lange Listen: `ComboBox1.FilterMode := fmContains;`
TPPGCustomComboBox.ItemHeight = Mindesthöhe einer Listenzeile in logischen Pixeln (0..1000); 0 = aus der Schrift. Einträge mit Detailzeile werden entsprechend höher.
TPPGCustomComboBox.ItemIndex = Index des gewählten Eintrags; -1 = keiner. Setzen aus Code löst (wie bei TComboBox) kein Ereignis aus.
> `ComboBox1.ItemIndex := ComboBox1.Items.IndexOf('Berlin');`
TPPGCustomComboBox.Items = Die Einträge als einfache Textliste (wie TComboBox.Items). Sind ItemsEx-Einträge vorhanden, enthält Items deren Texte.
TPPGCustomComboBox.ItemsEx = Reiche Einträge mit Bild (aus Images), Detailzeile, Plakette und Markup. Sind welche vorhanden, sind sie die Einträge der Liste.
> `with ComboBox1.ItemsEx.Add('Berlin', 2) do Detail := '3,7 Mio. Einwohner';`
TPPGCustomComboBox.Styles = Bereiche der Aufklappliste einzeln gestalten: Auswahl (aktueller Wert), Zebra-Zeilen, Hover, Gruppenkopf, Detailzeile. Nicht gesetzte Farben kommen aus dem Preset.
> `ComboBox1.Styles.AlternateRow.Color := $00FAF7F2;`
TPPGCustomComboBox.OnCloseUp = Die Aufklappliste wurde geschlossen (mit oder ohne Übernahme).
TPPGCustomComboBox.OnCustomDrawItem = Vor dem Zeichnen jedes Eintrags der Aufklappliste: Style (Fill, TextColor, BorderColor, FontStyle) ändern oder mit DefaultDraw := False selbst auf Canvas zeichnen.
> `if Index = 0 then Style.FontStyle := [fsBold];`
TPPGCustomComboBox.OnDropDown = Die Liste klappt gleich auf; hier lassen sich Einträge noch nachladen.
TPPGCustomComboBox.OnSelect = Der Anwender hat einen Eintrag gewählt (Klick, Enter, Pfeiltasten im geschlossenen Feld). Kommt nach OnClick; ist OnSelect nicht zugewiesen, wird stattdessen OnChange ausgelöst. Nicht bei ItemIndex aus Code.
TPPGCustomComboBox.Sorted = True: Die Einträge werden alphabetisch sortiert gehalten.
TPPGCustomComboBox.Style = csDropDown: freie Eingabe im Feld plus Liste (mit AutoComplete und FilterMode); csDropDownList: nur Auswahl aus der Liste, Tippen springt per Anfangsbuchstaben. csSimple verhält sich wie csDropDown, csOwnerDraw* wie csDropDownList (Zeichnen über OnCustomDrawItem).
TPPGCustomComboBox.Text = Der angezeigte bzw. eingegebene Text. Bei csDropDownList der Text des gewählten Eintrags.

# --- TPPGCustomDBGrid ---
TPPGCustomDBGrid.CardLabelWidth = Kartenansicht: Breite der Beschriftung links in der Karte (logische Pixel, 0..2000; Vorgabe 110). 0 = ohne Beschriftung, der Wert nutzt die ganze Breite. Der Wert behält mindestens 24 Pixel.
TPPGCustomDBGrid.CardSpacing = Kartenansicht: Abstand zwischen den Karten und zum Rand in logischen Pixeln (0..200; Vorgabe 8).
TPPGCustomDBGrid.CardWidth = Kartenansicht: Breite einer Karte in logischen Pixeln (60..4000; Vorgabe 280). Ist die Ansicht schmaler, wird die Karte schmaler. Die Höhe ergibt sich aus den sichtbaren Spalten (eine Zeile je Feld).
TPPGCustomDBGrid.EditMode = dgeCells: Bearbeiten in der Zelle wie TDBGrid. dgeForm: Bearbeitungsformular in der Zeile – Enter, F2, Doppelklick, Tippen oder ShowEditForm klappen unter der aktuellen Zeile einen Bereich mit allen Feldern auf (Beschriftung und Editor je Feld im Raster, Schaltflächen Übernehmen/Abbrechen); die folgenden Zeilen rücken nach unten. Übernehmen schreibt die Werte und bucht (Post), ein Fehler (ungültiger Wert, Pflichtfeld, BeforePost) lässt das Formular offen und setzt den Fokus auf das Feld; Abbrechen bzw. Esc verwirft (Cancel). Einfg legt einen neuen Datensatz im Formular an. Wechselt der Datensatz (Navigator, Klick auf eine andere Zeile), bucht die Datenmenge wie üblich und das Formular schließt. Die Zellen selbst sind in diesem Modus nicht bearbeitbar. Nur in der Tabelle; die Kartenansicht bearbeitet immer in der Zelle.
> `PPGDBGrid1.EditMode := dgeForm; PPGDBGrid1.EditForm.ColumnCount := 3;`
TPPGCustomDBGrid.EditForm = Einstellungen des Bearbeitungsformulars (EditMode = dgeForm): Spalten des Rasters, Breite der Beschriftung, Schaltflächen.
TPPGCustomDBGrid.OnEditFormShow = Das Bearbeitungsformular wurde geöffnet (Editoren gefüllt, Fokus gesetzt). Werte, die der Handler in die Editoren schreibt (EditFormEditor), gelten als Eingabe und werden beim Übernehmen geschrieben.
> `procedure TForm1.GridEditFormShow(Sender: TObject); begin StatusBar1.SimpleText := 'Bearbeiten'; end;`
TPPGCustomDBGrid.OnEditFormClose = Das Bearbeitungsformular wurde geschlossen; Accepted = True nach Übernehmen, False nach Abbrechen bzw. wenn der Datensatz von außen gewechselt hat.
TPPGDBGridEditFormOptions.ColumnCount = Spalten des Rasters im Bearbeitungsformular (1..8; Vorgabe 2). Je Spalte steht ein Feld als Beschriftung + Editor; die Felder fließen in der Reihenfolge der Spalten nach rechts und brechen um.
TPPGDBGridEditFormOptions.LabelWidth = Breite der Beschriftung links vom Editor in logischen Pixeln (0..1000; Vorgabe 120). 0 = ohne Beschriftung; höchstens die halbe Breite eines Felds.
TPPGDBGridEditFormOptions.ShowButtons = True: Schaltflächen Übernehmen und Abbrechen unten im Formular. False: nur Tastatur (Strg+Enter, Esc; Enter im letzten Feld übernimmt).
TPPGDBGridColumn.EditFormVisible = Feld der Spalte im Bearbeitungsformular: efvAuto wie Visible, efvShow immer (auch ausgeblendete Spalten, z. B. Bemerkungen), efvHide nie (z. B. berechnete Spalten).
TPPGDBGridColumn.EditFormColSpan = Spalten des Formular-Rasters, die das Feld belegt (1..8; höchstens EditForm.ColumnCount), z. B. 2 für lange Texte.
TPPGCustomDBGrid.DataSource = Die Datenquelle, deren Datenmenge das Grid zeigt. Ohne Columns erscheinen alle sichtbaren Felder (Titel = DisplayLabel, Breite aus DisplayWidth).
> `PPGDBGrid1.DataSource := DataSource1;`
TPPGCustomDBGrid.ExportMaxRecords = Drucken und Export lesen höchstens so viele Datensätze (Schutz vor sehr großen Tabellen). Vorgabe 100000.
TPPGCustomDBGrid.OnCellClick = Klick mit der linken Maustaste auf eine Datenzelle; Column ist die angeklickte Spalte (Column.Field liefert das Feld).
TPPGCustomDBGrid.OnGetFooterText = Text der Summenzeile (ShowFooter) für eine Spalte. Text ist mit dem Wert aus Column.FooterField vorbelegt und kann ersetzt werden; die ganze Datenmenge liest das Grid dafür nie.
> `if Column.FieldName = 'Betrag' then Text := FormatFloat('#,##0.00 €', SummeAusAbfrage);`
TPPGCustomDBGrid.OnSelectionChanged = Die Mehrfachauswahl (SelectedRows, nur mit dgMultiSelect) hat sich geändert: per Maus, Tastatur oder Code. Bereiche und SelectAll lösen das Ereignis einmal aus.
> `StatusBar1.SimpleText := Format('%d ausgewählt', [PPGDBGrid1.SelectedRows.Count]);`
! Für Zähler in der Statusleiste und zum Freischalten von Knöpfen, die mit mehreren Datensätzen arbeiten (Löschen, Exportieren, Sammelbuchung).
TPPGCustomDBGrid.OnDrawColumnCell = Wie TDBGrid.OnDrawColumnCell: nach dem Zeichnen einer Datenzelle (nach OnDrawCell) selbst auf Canvas zeichnen. DataCol ist der Index der Spalte in Columns, Column die Spalte, State enthält gdSelected (Auswahl und Mehrfachauswahl) und gdFocused. Canvas ist mit Schrift, Textfarbe und Pinselfarbe der Zelle vorbereitet (Theme, Dunkelmodus); die Datenmenge steht auf dem gezeichneten Satz, Column.Field liefert dessen Werte. DefaultDrawColumnCell zeichnet den Standardinhalt.
> `if Column.Field.AsCurrency < 0 then PPGDBGrid1.Canvas.Font.Color := clRed; PPGDBGrid1.DefaultDrawColumnCell(Rect, DataCol, Column, State);`
! Für Einfärbungen, die vom ganzen Datensatz abhängen (überfällig, gesperrt), und für migrierte TDBGrid-Handler. Für reine Werteregeln reichen ConditionalFormats und OnGetCellStyle. Die Datenmenge im Ereignis nicht bewegen.
TPPGCustomDBGrid.OnTitleClick = Klick auf einen Spaltentitel (mit dgTitleClick in Options). Sortieren ist Sache der Datenmenge, z. B. IndexFieldNames setzen.
> `FDQuery1.IndexFieldNames := Column.FieldName;`
TPPGCustomDBGrid.Options = Verhalten wie bei TDBGrid: dgEditing (bearbeiten), dgTitles (Titelzeile), dgIndicator (Datensatzzeiger links), dgColumnResize (Spaltenbreite und -position ändern), dgColLines/dgRowLines (Gitterlinien), dgTabs, dgRowSelect, dgAlwaysShowSelection, dgConfirmDelete (Rückfrage bei Strg+Entf), dgCancelOnExit, dgTitleClick, dgTitleHotTrack, dgMultiSelect (Mehrfachauswahl von Datensätzen, siehe SelectedRows).
TPPGCustomDBGrid.ReadOnly = True: Keine Bearbeitung im Grid, auch wenn die Datenmenge änderbar ist.

# --- TPPGCustomDatePicker ---
TPPGCustomDatePicker.CalAlignment = Ausrichtung des aufklappenden Kalenders am Feld: dtaLeft = linke Kante, dtaRight = rechte Kante (bei RTL gespiegelt).
TPPGCustomDatePicker.Styles = Bereiche des aufklappenden Kalenders einzeln gestalten (Kopf, Wochentage, Wochenende, Heute, Auswahl, andere Monate, Wochennummern).
> `DatePicker1.Styles.Weekend.TextColor := clRed;`
TPPGCustomDatePicker.Checked = Nur mit ShowCheckbox: True = ein Datum ist gesetzt, False = „kein Datum".
TPPGCustomDatePicker.Date = Das gewählte Datum (ohne Uhrzeit). Setzen aus Code löst kein OnChange aus; Werte außerhalb MinDate/MaxDate werden begrenzt.
> `DatePicker1.Date := IncDay(Date, 7);`
TPPGCustomDatePicker.DateFormat = dfShort (kurzes Datum, z. B. 08.10.2026) oder dfLong (langes Datum mit Wochentag) nach den Ländereinstellungen, wenn Format leer ist.
TPPGCustomDatePicker.DateMode = dmComboBox: Kalender zum Aufklappen. dmUpDown: Auf/Ab-Knöpfe statt Kalender (Tag, mit Strg Monat), kein Aufklappen.
TPPGCustomDatePicker.Format = Eigenes Anzeigeformat nach FormatDateTime (z. B. „dd.mm.yyyy" oder „ddd, d. mmmm"); leer = DateFormat.
TPPGCustomDatePicker.Kind = dtkDate: Datum mit Kalender. dtkTime: Uhrzeit (LongTimeFormat bzw. Format), Auf/Ab-Knöpfe statt Kalender, Oben/Unten = Minute, Strg = Stunde; der Datumsteil bleibt erhalten. dtkDateTime (ab Delphi 10.4): Datum und Uhrzeit. Der DB-DatePicker überträgt bei Uhrzeit den ganzen Wert.
> `DatePicker1.Kind := dtkTime; DatePicker1.Time := EncodeTime(9, 30, 0, 0);`
TPPGCustomDatePicker.MaxDate = Spätestes wählbares Datum; 0 = keine Grenze. Spätere Tage sind im Kalender gesperrt, Eingaben werden begrenzt.
TPPGCustomDatePicker.MinDate = Frühestes wählbares Datum; 0 = keine Grenze.
> `DatePicker1.MinDate := Date;` (nur heute und später)
TPPGCustomDatePicker.OnCloseUp = Der Kalender wurde geschlossen (mit oder ohne Übernahme).
TPPGCustomDatePicker.OnCustomDrawDay = Vor dem Zeichnen jedes Tages im aufklappenden Kalender: Style für ADate ändern (z. B. Feiertage fett und rot) oder mit DefaultDraw := False selbst zeichnen.
> `if IstFeiertag(ADate) then begin Style.TextColor := clRed; Style.FontStyle := [fsBold]; end;`
TPPGCustomDatePicker.OnDropDown = Der Kalender klappt gleich auf.
TPPGCustomDatePicker.ParseInput = True: Beim Übernehmen der Eingabe wird zuerst OnUserInput gefragt (eigene Auswertung, z. B. „morgen“ oder „+3“). DateAndTime kommt mit dem gelesenen bzw. bisherigen Wert; AllowChange := False lehnt ab (ValidationState = pvsError). Ohne Ereignis gilt die normale Prüfung.
> `DatePicker1.ParseInput := True; DatePicker1.OnUserInput := Eingabe;`
TPPGCustomDatePicker.ShowCheckbox = True: Links im Feld erscheint ein Kontrollkästchen; ohne Haken (Checked = False) gilt „kein Datum".
TPPGCustomDatePicker.Time = Uhrzeitanteil des Werts (wie TDateTimePicker.Time). Angezeigt und bearbeitet wird er mit Kind = dtkTime bzw. dtkDateTime; mit dtkDate zeigt das Feld nur das Datum, die Uhrzeit bleibt erhalten.

# --- TPPGCustomEdit ---
TPPGCustomEdit.AutoSelect = True: Beim Fokus per Tab wird der ganze Text markiert.
TPPGCustomEdit.LeftButton = Bild-Schaltfläche links im Feld (wie TButtonedEdit): Visible, ImageIndex (aus Images), Enabled, DropDownMenu. Klick löst OnLeftButtonClick aus und öffnet ggf. das Menü.
> `Edit1.Images := ImageList1; Edit1.LeftButton.ImageIndex := 0; Edit1.LeftButton.Visible := True;`
TPPGCustomEdit.NumbersOnly = True: Nur Ziffern können eingegeben werden (wie TEdit.NumbersOnly). Für Zahlen mit Komma und Grenzen besser TPPGNumberEdit.
TPPGCustomEdit.OnLeftButtonClick = Die linke Schaltfläche (LeftButton) wurde geklickt.
TPPGCustomEdit.OnRightButtonClick = Die rechte Schaltfläche (RightButton) wurde geklickt, z. B. um einen Suchdialog zu öffnen.
TPPGCustomEdit.PasswordChar = Zeichen, das statt der Eingabe angezeigt wird (z. B. „●"); #0 = Klartext. Für Kennwörter mit Aufdecken-Knopf besser TPPGPasswordEdit.
TPPGCustomEdit.RightButton = Bild-Schaltfläche rechts im Feld: Visible, ImageIndex (aus Images), Enabled, DropDownMenu. Klick löst OnRightButtonClick aus und öffnet ggf. das Menü.
> `Edit1.RightButton.ImageIndex := 1; Edit1.RightButton.Visible := True; Edit1.RightButton.DropDownMenu := PopupMenu1;`

# --- TPPGCustomField.Text ---
TPPGCustomField.Text = Der Inhalt des Felds. Setzen aus Code löst OnChange aus (wie bei TEdit).
> `Edit1.Text := '';`

# --- TPPGCustomGrid ---
TPPGCustomGrid.Bands = Bänder: Überschriften über mehreren Spalten, auch mehrstufig (ParentBand). Welche Spalten darunter stehen, legt Column.Band fest.
> `Grid1.Bands.Add.Caption := 'Adresse'; Grid1.Columns[2].Band := 0; Grid1.Columns[3].Band := 0;`
TPPGCustomGrid.BorderStyle = bsSingle: Rahmen nach Appearance; bsNone: ohne Rahmen.
TPPGCustomGrid.ColCount = Anzahl der Spalten einschließlich fester Spalten (1..100000), wie TStringGrid.
TPPGCustomGrid.Columns = Spaltendefinitionen: Titel, Breite, Ausrichtung, Editor, Zellart, Summe, Gruppierung, Stile. Ohne Einträge gelten Standardspalten mit DefaultColWidth.
> Im Designer per Doppelklick; im Code `with Grid1.Columns.Add do begin Title := 'Preis'; Alignment := taRightJustify; Aggregate := agSum; end;`
TPPGCustomGrid.ConditionalFormats = Bedingte Formate ohne Code: Regeln je Spalte (Wertbereich, gleich, enthält, oberste/unterste N, Farbskala, Datenbalken, Symbolsatz) mit Farben aus dem Theme.
> `with Grid1.ConditionalFormats.Add do begin Column := 3; Rule := crDataBar; Color := ccAccent; end;`
TPPGCustomGrid.DefaultColWidth = Breite der Spalten ohne eigene Breite in logischen Pixeln (1..10000).
TPPGCustomGrid.DefaultDrawing = False: Der Zelltext wird nicht gezeichnet (Hintergrund, Linien und Auswahl schon); den Inhalt zeichnet man in OnDrawCell selbst.
TPPGCustomGrid.DefaultRowHeight = Höhe der Zeilen ohne eigene Höhe in logischen Pixeln (1..10000).
TPPGCustomGrid.DrawingStyle = Wie TStringGrid: gdsGradient zeichnet den Kopf als Verlauf von GradientStartColor nach GradientEndColor (nur im Hellen); gdsClassic und gdsThemed nehmen den Kopf vom Preset bzw. aus Styles.Header.
TPPGCustomGrid.FixedColor = Wie TStringGrid.FixedColor: Hintergrund des Kopfs. Ist ein Alias für Styles.Header.Color und wird nicht eigens gespeichert; clBtnFace bedeutet „vom Preset".
> `Grid1.FixedColor := $00F0E6DC;`
TPPGCustomGrid.FixedCols = Anzahl fester Spalten links, die beim waagerechten Scrollen stehen bleiben (0..ColCount-1).
TPPGCustomGrid.FixedColsRight = Anzahl Spalten, die rechts fest stehen bleiben (0..100), z. B. eine Aktions- oder Summenspalte.
TPPGCustomGrid.FixedRows = Anzahl fester Kopfzeilen oben (0..RowCount-1).
TPPGCustomGrid.GradientEndColor = Endfarbe des Kopf-Verlaufs bei DrawingStyle = gdsGradient.
TPPGCustomGrid.GradientStartColor = Anfangsfarbe des Kopf-Verlaufs bei DrawingStyle = gdsGradient.
TPPGCustomGrid.GridLineWidth = Breite der Gitterlinien in logischen Pixeln (0..10; 0 = keine Linien). Farbe über Styles.GridLine.Color.
TPPGCustomGrid.GroupFooter = True: Unter jeder Gruppe steht eine Fußzeile mit den Summen (Column.Aggregate).
TPPGCustomGrid.HeaderMenu = True: Rechtsklick auf den Kopf öffnet ein Menü zum Sortieren, Ausblenden, Wählen der Spalten und Anpassen der Breite. Ergänzen lässt es sich in OnHeaderMenu.
TPPGCustomGrid.OnCellButtonClick = Eine Schaltfläche in einer Zelle mit CellKind = ckButton wurde geklickt (ACol, ARow = Datenspalte und -zeile).
> `if ACol = 4 then LoescheZeile(ARow);`
TPPGCustomGrid.OnColEnter = Die Fokusspalte hat gewechselt (Maus, Tastatur oder Code); die neue Spalte ist schon aktiv (wie TDBGrid.OnColEnter).
TPPGCustomGrid.OnColExit = Die Fokusspalte wird verlassen; die alte Spalte ist noch aktiv (wie TDBGrid.OnColExit).
TPPGCustomGrid.OnEditButtonClick = Der „…“-Knopf im Editor einer Spalte mit ButtonStyle = cbsEllipsis wurde geklickt oder Strg+Enter gedrückt (wie TDBGrid.OnEditButtonClick). Typisch: Auswahldialog öffnen und den Wert ins Feld schreiben.
> `procedure TForm1.Grid1EditButtonClick(Sender: TObject); begin if KundeWaehlen(Nr) then Table1.FieldByName('KundeNr').AsInteger := Nr; end;`
TPPGCustomScrollControl.ScrollBars = Welche Bildlaufleisten es gibt: ssBoth (Vorgabe), ssVertical, ssHorizontal oder ssNone (wie TStringGrid.ScrollBars). Mausrad und Tastatur scrollen auch ohne Leiste.
TPPGCustomGrid.OnColumnMoved = Der Anwender hat eine Spalte verschoben; FromIndex und ToIndex sind Anzeige-Positionen.
TPPGCustomGrid.OnCompareCells = Eigener Vergleich beim Sortieren: Compare < 0, = 0 oder > 0 setzen (Zeile ARow1 vor, gleich oder nach ARow2). Ohne Ereignis vergleicht das Grid Zahlen numerisch, sonst als Text.
> `Compare := CompareDate(StrToDate(Cells[ACol, ARow1]), StrToDate(Cells[ACol, ARow2]));`
TPPGCustomGrid.OnCustomAggregate = Wert für Spalten mit Aggregate = agCustom: Value für Spalte ACol in Gruppe Group setzen (Group = -1 = Summenzeile). Die Zeilen der Gruppe liefert GroupDataRows(Group).
TPPGCustomGrid.OnDrawCell = Nach dem Standardzeichnen einer Zelle zusätzlich auf Canvas zeichnen (Rect, State mit gdSelected, gdFocused, gdFixed). Mit DefaultDrawing = False zeichnet man so den ganzen Zellinhalt selbst. ACol und ARow sind Datenspalte und -zeile.
TPPGCustomGrid.OnFixedCellClick = Klick auf eine feste Zelle (Kopf oder feste Spalte).
TPPGCustomGrid.OnGetCellStyle = Darstellung je Zelle nach den bedingten Formaten: Style.Fill, TextColor, Bold, FontStyle, FontName, FontSize, Datenbalken (Bar, BarColor) und Symbol (Icon, IconColor) setzen.
> `if StrToFloatDef(Grid1.Cells[ACol, ARow], 0) < 0 then Style.TextColor := clRed;`
TPPGCustomGrid.OnGetCellText = Virtuelle Daten: liefert den Text einer Zelle, ohne dass er in Cells[] steht (z. B. für eine Million Zeilen aus einer eigenen Liste).
> `Text := FDaten[ARow - 1].Name;`
TPPGCustomGrid.OnGetEditText = Wie TStringGrid: Text, mit dem der Editor einer Zelle startet (z. B. ein Rohwert statt der formatierten Anzeige).
TPPGCustomGrid.OnGetGroupText = Text einer Gruppenzeile (Markup erlaubt); Group ist der Index für GroupInfo.
> `Text := Format('<b>%s</b> (%d)', [GroupInfo(Group).Key, GroupInfo(Group).Count]);`

# --- TPPGGridPrinter ---
TPPGGridPrinter.FitToPageWidth = True: Alle Spalten werden auf die Seitenbreite verkleinert; False: zu breite Tabellen gehen auf weiteren Seiten nebeneinander weiter.
TPPGGridPrinter.Grid = Das Grid bzw. DB-Grid, das gedruckt wird (mit seiner aktuellen Ansicht: Sortierung, Filter, sichtbare Spalten).
> `PPGGridPrinter1.Grid := PPGGrid1; PPGGridPrinter1.Preview;`
TPPGGridPrinter.PrintColors = True: Zellfarben (bedingte Formate, Zebra) werden mitgedruckt; False: nur Schwarz auf Weiß.
TPPGGridPrinter.PrintGridLines = True: Gitterlinien werden gedruckt.
TPPGGridPrinter.RepeatHeader = True: Die Spaltenköpfe stehen auf jeder Seite.
TPPGGridPrinter.UseGridLook = True (Vorgabe): Der Ausdruck sieht aus wie das Grid in heller Darstellung – Schrift, Kopf- und Bandzeilen, Spalten- und Zebra-Stile, bedingte Formate, Gruppenzeilen, verbundene Zellen und die Summenzeile am Ende der letzten Seite; ein Gruppenkopf bleibt nie allein am Seitenende. False: grauer, fetter Kopf und nur Datenzeilen wie früher. Auch im Dialog „Seite einrichten“ umschaltbar.

# --- TPPGGridStyles ---
TPPGGridStyles.AlternateRow = Zebra: jede zweite Datenzeile. Erst Color setzen schaltet es ein.
TPPGGridStyles.FilterRow = Die Filterzeile unter dem Kopf (ShowFilterRow).
TPPGGridStyles.FocusedCell = Die Zelle mit Tastaturfokus: BorderColor = Rahmen, Color = Fläche, TextColor = Text.
TPPGGridStyles.Footer = Summenzeile (ShowFooter) und Gruppenfuß; ohne eigene Werte wie Header.
TPPGGridStyles.GridLine = Gitterlinien: Color = Linienfarbe (Breite über GridLineWidth).
TPPGGridStyles.GroupRow = Gruppenkopf-Zeilen beim Gruppieren.
TPPGGridStyles.Header = Kopfzeilen, feste Spalten und Bänder: Color = Fläche, TextColor = Text, BorderColor = Linien im Kopf, Font/FontStyle = Schrift.
> `Grid1.Styles.Header.Color := clNavy; Grid1.Styles.Header.TextColor := clWhite;`
TPPGGridStyles.HotRow = Zeile unter der Maus. Erst Color setzen schaltet die Hervorhebung ein.
TPPGGridStyles.Selection = Auswahl, solange das Grid den Fokus hat. Mit gesetzter Color wird sie deckend statt halbtransparent gezeichnet.
TPPGGridStyles.SelectionInactive = Auswahl, wenn das Grid den Fokus nicht hat.

# --- TPPGTagEdit ---
TPPGTagEdit.AddOnExit = True: Beim Verlassen des Felds wird angefangener Text zum Tag.
TPPGTagEdit.AllowDuplicates = True: Dasselbe Tag darf mehrfach vorkommen.
TPPGTagEdit.AllowNew = False: Nur Einträge aus Suggestions sind erlaubt (Auswahlliste statt freier Eingabe).
TPPGTagEdit.CaseSensitive = True: Groß-/Kleinschreibung zählt beim Prüfen auf Doppelte und beim Abgleich mit Suggestions.
TPPGTagEdit.Delimiter = Trennzeichen der Tags in TagsText bzw. im DB-Feld. Vorgabe „;".
TPPGTagEdit.InputDelimiters = Zeichen, die beim Tippen ein Tag abschließen (z. B. „;," ). Enter schließt immer ab; eingefügtes „a; b; c" ergibt drei Tags.
TPPGTagEdit.MaxTags = Höchstzahl der Tags; 0 = ohne Grenze.
TPPGTagEdit.OnTagAdding = Bevor ein Tag durch den Anwender entsteht: Tag kann geändert (z. B. getrimmt) werden, Allow := False lehnt ab.
> `Allow := Pos('@', Tag) > 0; // nur E-Mail-Adressen`
TPPGTagEdit.OnTagClick = Ein Tag (Chip) wurde angeklickt.
TPPGTagEdit.OnTagRemoved = Der Anwender hat ein Tag entfernt (Klick auf ×, Entf oder Rücktaste).
TPPGTagEdit.Suggestions = Vorschläge, die beim Tippen im Aufklappfenster erscheinen.
> `TagEdit1.Suggestions.CommaText := 'Vertrieb,Einkauf,Technik';`
TPPGTagEdit.Tags = Die aktuellen Tags, je Zeile eines. Änderungen aus Code lösen keine Ereignisse aus.
> `TagEdit1.Tags.Add('Wichtig');`
TPPGCustomDatePicker.OnUserInput = Nur mit ParseInput = True: Die Eingabe wird übernommen (Enter, Fokusverlust). UserString ist der eingegebene Text, DateAndTime kommt mit dem gelesenen bzw. bisherigen Wert und kann ersetzt werden; AllowChange := False lehnt ab (Feld wird rot markiert).
> `if SameText(UserString, 'morgen') then DateAndTime := Date + 1 else if UserString = '' then AllowChange := False;`
# Gruppe 5, Schritt 6a: Filter, Suche, Ereignisse
TPPGCustomGrid.FilterImmediate = True: Die Filterzeile filtert schon beim Tippen (der Editor bleibt offen); False: erst mit Enter bzw. beim Verlassen der Zelle.
TPPGCustomGrid.ShowFilterBar = True: Bei aktivem Filter steht unten eine Leiste mit dem Filter als Text (z. B. „Name enthält mül und Betrag > 100“) und dem Link „Filter löschen“.
TPPGCustomGrid.FindPanel = Suchfeld über der Tabelle: fpmNone (keins), fpmManual (Strg+F blendet es ein, Esc bzw. Schließen aus) oder fpmAlways (immer sichtbar). Gesucht wird ohne Groß-/Kleinschreibung in allen sichtbaren Textspalten; Treffer sind markiert, Enter/F3 springt weiter, Umschalt+Enter/Umschalt+F3 zurück.
> `Grid1.FindPanel := fpmManual; Grid1.FindText := 'Müller'; Grid1.FindNext;`
TPPGCustomGrid.IncrementalSearch = True: Tippen in einer nicht bearbeitbaren Zelle springt zur nächsten Zeile, deren Text in der Fokusspalte so beginnt (Zeichen sammeln sich bis zu einer Pause von einer Sekunde; Esc beginnt neu).
TPPGCustomGrid.OnFilterChanged = Ein Filter der Filterzeile hat sich geändert (Eingabe, Filters[], ClearFilters, Filterleiste). FilterDescription liefert ihn als Text.
TPPGCustomDBGrid.ShowFilterRow = True: Unter dem Kopf erscheint eine Eingabezeile; Text je Spalte filtert die Datenmenge über OnFilterRecord (Operatoren wie bei TPPGGrid; Zahl und Datum nach Feldtyp, Kästchen mit 1/0, Nachschlagespalten über den Text). Ein eigener OnFilterRecord und Filter/Filtered der Anwendung bleiben in Kraft und kommen beim Löschen der Filter zurück.
TPPGCustomDBGrid.SortOnHeaderClick = True: Klick auf einen Spaltenkopf setzt nur den Sortierpfeil (SortColumn, SortAscending) und meldet OnSorted bzw. OnTitleClick; sortieren muss die Datenmenge (z. B. IndexFieldNames). Vorgabe False.
TPPGCustomDBGrid.OnFocusedRecordChanged = Der aktuelle Datensatz ist ein anderer geworden (Blättern, Klick, Suche, Einfügen, Abbrechen); nicht beim Ändern von Werten desselben Satzes.
TPPGCustomDBGrid.OnCanSelectRecord = Mehrfachauswahl: vor dem Wählen eines Datensatzes (Klick, Umschalt-Bereich, Strg+A, SelectedRows); die Datenmenge steht auf dem Satz, Allow := False lehnt ihn ab.
TPPGCustomDBGrid.OnSelectCell = Vor dem Wechsel der Fokuszelle bzw. des Datensatzes; CanSelect := False verhindert ihn. RowValue('Feld') liefert dabei schon die Werte der Zielzeile.

# --- Grid-Wünsche: Enter, Sortieren, Filter nach Werten, Suche, Datumsgruppen ---
TPPGCustomGrid.EnterMovesNext = True: Enter springt zur nächsten Zelle (Spalte rechts, am Zeilenende erste Spalte der nächsten Datenzeile; Gruppenzeilen werden übersprungen). Im Editor wird der Wert zuerst übernommen (lehnt OnValidateCell ab, bleibt der Editor offen). Ohne Editor öffnet Enter dann keinen Editor mehr, F2 und Tippen schon. DB-Grid: am Zeilenende der nächste Satz der Datenmenge (bucht wie Pfeil runter), am letzten Satz wird nichts angehängt.
> `Grid1.EnterMovesNext := True;`
TPPGCustomGrid.FindExtendedSyntax = True: Das Suchfeld (FindText) versteht mehrere Begriffe: Leerzeichen trennen Begriffe, von denen einer vorkommen muss (oder); „+wort“ muss, „-wort“ darf in der Zeile nicht vorkommen; ein Text in Anführungszeichen ist ein Begriff mit Leerzeichen; % steht für beliebig viele, _ für genau ein Zeichen. Die Begriffe gelten für die ganze Zeile (alle durchsuchten Spalten), Treffer ist eine Zelle mit einem Begriff ohne „-“. False: der ganze Text ist ein Begriff.
> `Grid1.FindExtendedSyntax := True; Grid1.FindText := 'schraube +m8 -verzinkt';`
TPPGCustomGrid.FilterValueMenu = True: Das Kopfmenü bekommt „Nach Wert filtern“ mit den verschiedenen Werten der Spalte zum An- und Abhaken („(Alle)“ hebt den Filter auf, „(Leer)“ steht für leere Zellen). Der Filter ist eine Werteliste („=a|b|“, siehe Filters). DB-Grid: die Werte kommen aus der (schon gefilterten) Datenmenge bzw. gruppiert aus dem Speicher.
TPPGCustomGrid.OnCellDblClick = Doppelklick auf eine Datenzelle (auch eine Karte der Kartenansicht); ACol = Datenspalte, ARow = Datenzeile (DB-Grid: Zeile im Puffer bzw. der gruppierten Ansicht, der Satz ist dann der aktive). Kopf, Gruppen- und Filterzeile lösen es nicht aus; OnDblClick kommt wie bisher immer.
> `procedure TForm1.Grid1CellDblClick(Sender: TObject; ACol, ARow: Integer); begin OeffneArtikel; end;`
TPPGCustomGrid.OnSortRequest = Der Anwender will sortieren (Kopfklick mit SortOnHeaderClick, Kopfmenü). Direction (gsdAscending, gsdDescending, gsdNone) lässt sich ändern, etwa absteigend in keine Sortierung, wenn die Datenmenge das nicht kann; Accept := False lässt alles, wie es ist. Danach sortiert das Grid bzw. setzt den Pfeil und meldet OnSorted.
> `if Direction = gsdDescending then Direction := gsdNone;`
TPPGCustomGrid.OnGetFilterValues = Werte für „Nach Wert filtern“ (FilterValueMenu) einer Spalte: Values ändern, ergänzen oder leeren (z. B. feste Werte statt der vorhandenen).
TPPGGridColumn.VisibleForCustomization = False: Die Spalte fehlt in der Spaltenauswahl des Kopfmenüs und lässt sich dort weder aus- noch einblenden („Alle einblenden“ lässt sie aus). Visible per Code wirkt weiter, z. B. für Schlüsselspalten.
TPPGGridColumn.GroupDateMode = Gruppieren einer Datumsspalte: gdmValue (nach dem angezeigten Wert), gdmDay, gdmWeek (Kalenderwoche nach ISO), gdmMonth, gdmQuarter, gdmYear oder gdmRelative (Heute, Gestern, Morgen, Früher/Später in dieser Woche, Letzte/Nächste Woche, Älter, Später). Gruppen stehen nach dem Datum, nicht alphabetisch; Zellen ohne Datum gruppieren nach ihrem Text.
> `Grid1.Columns[3].GroupDateMode := gdmMonth; Grid1.GroupBy([3]);`
TPPGCustomDBGrid.AllowEdit = False: Bestehende Sätze lassen sich weder in der Zelle noch im Bearbeitungsformular ändern (neue Sätze folgen AllowInsert). Wirkt zusätzlich zu ReadOnly und Options (dgEditing).
TPPGCustomDBGrid.AllowInsert = False: Einfg und Pfeil runter am Ende legen keinen Satz an; ein neuer Satz (von außen) ist nicht bearbeitbar.
TPPGCustomDBGrid.AllowDelete = False: Strg+Entf löscht weder den Satz noch die Mehrfachauswahl.
TPPGCustomDBGrid.SortIndicatorFromIndex = True: Der Sortierpfeil folgt IndexFieldNames der Datenmenge (erstes Feld; „:D“ bzw. „ DESC“ = absteigend), beim Öffnen und nach jeder Änderung der Datenmenge, nicht beim Blättern. Ohne passende Spalte verschwindet der Pfeil. OnSorted kommt dabei nicht.
TPPGCustomDBGrid.CardAutoWidth = Kartenansicht, True: Die Karten teilen sich die ganze Breite (CardWidth ist dann die Mindestbreite und bestimmt, wie viele nebeneinander passen).
TPPGCustomDBGrid.CardAreaColor = Kartenansicht: Farbe der Fläche zwischen den Karten (clDefault = Theme). Im Hochkontrast gilt das Theme.
TPPGDBGridColumn.EditFormIndex = Reihenfolge im Bearbeitungsformular (-1..9999; -1 = wie die Anzeige). Felder mit Index stehen zuerst, nach dem Index aufsteigend (gleicher Index: Anzeige-Reihenfolge), danach die übrigen. Abschnitte (EditFormGroup) folgen dieser Reihenfolge.
> `TPPGDBGridColumn(DBGrid1.Columns[5]).EditFormIndex := 0;`
TPPGDBGridColumn.EditFormNewRow = True: Das Feld beginnt im Formular eine neue Rasterzeile (links), auch wenn daneben noch Platz wäre.
TPPGCustomDBGrid.KeyFieldNames = Schlüsselfelder der Datenmenge als Semikolon-Liste (z. B. `ID` oder `Kunde;Nummer`), eindeutig je Satz. Gruppiert merkt sich das Grid je Zeile die Schlüsselwerte und stellt die Datenmenge per Locate statt per Lesezeichen auf den Satz; steht sie schon dort, passiert nichts. Auch Auswahl, Neulesen und der Vergleich des aktiven Satzes (OnFocusedRecordChanged, Editor) nutzen dann die Schlüssel; beim Laden der Gruppen holt das Grid keine Lesezeichen. Leer oder ein unbekanntes Feld = Lesezeichen wie bisher.
> `PPGDBGrid1.KeyFieldNames := 'ID';`
TPPGCustomDBGrid.GroupSyncDelay = Gruppiert: Gehaltene Pfeil- bzw. Bild-Tasten (Tastenwiederholung) bewegen nur den Fokus; die Datenmenge folgt einmal beim Loslassen bzw. so viele Millisekunden nach der letzten Wiederholung (0..5000; Vorgabe 120). Spätestens vor jedem Zugriff auf den aktiven Satz (Editor, Auswahl, RowValue, Aktionen, Verlassen des Grids) zieht das Grid nach. Einzelne Tastendrücke und Klicks wirken sofort. 0 = jeder Schritt sofort.
TPPGCustomDBGrid.SyncActiveRecord = Zieht eine noch ausstehende Positionierung der Datenmenge sofort nach (nach schnellem Blättern im gruppierten Modus); True, wenn die Datenmenge danach auf der fokussierten Zeile steht.
TPPGCustomDBGrid.RecordSyncPending = True, solange der Fokus nach schnellem Blättern weiter ist als die Datenmenge (GroupSyncDelay läuft noch).
