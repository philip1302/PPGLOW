# TPPGChartReferenceLines

Typ in Unit `PPG.Chart.Series` - Basis `TOwnedCollection`

Waagerechte oder senkrechte Referenzlinien (z. B. Ziel- oder Grenzwerte), die über dem Diagramm liegen.

Collection: Die Eintraege sind vom Typ [TPPGChartReferenceLine](TPPGChartReferenceLine.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.

## Verwendet in

[TPPGChart](../TPPGChart.md), [TPPGDBChart](../TPPGDBChart.md)
