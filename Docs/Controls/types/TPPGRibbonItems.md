# TPPGRibbonItems

Typ in Unit `PPG.Ribbon.Items` - Basis `TOwnedCollection`

Befehle einer Gruppe bzw. des Schnellzugriffs (Collection): Buttons, Split-Buttons, Umschalter, Galerien, eingebettete Controls und Trenner.

Nutzung: `G.Items.AddButton('Einfügen', $E77F, rsLarge, EinfuegenClick);`

Collection: Die Eintraege sind vom Typ [TPPGRibbonItem](TPPGRibbonItem.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.

## Verwendet in

[TPPGRibbon](../TPPGRibbon.md), [TPPGRibbonGroup](TPPGRibbonGroup.md)
