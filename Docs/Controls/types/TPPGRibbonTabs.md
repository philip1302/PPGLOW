# TPPGRibbonTabs

Typ in Unit `PPG.Ribbon.Items` - Basis `TOwnedCollection`

Die Registerkarten des Ribbons (Collection), auch Kontext-Registerkarten.

Nutzung: `PPGRibbon1.Tabs.AddTab('Start').Groups.AddGroup('Zwischenablage');`

Collection: Die Eintraege sind vom Typ [TPPGRibbonTab](TPPGRibbonTab.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.
