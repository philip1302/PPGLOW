# TPPGGridBands

Typ in Unit `PPG.Grid.Columns` - Basis `TOwnedCollection`

Bänder über den Spaltenköpfen: fassen benachbarte Spalten unter einer gemeinsamen Überschrift zusammen.

Collection: Die Eintraege sind vom Typ [TPPGGridBand](TPPGGridBand.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.

## Verwendet in

[TPPGDBGrid](../TPPGDBGrid.md), [TPPGGrid](../TPPGGrid.md)
