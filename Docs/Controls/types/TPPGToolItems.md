# TPPGToolItems

Typ in Unit `PPG.ToolBar` - Basis `TOwnedCollection`

Die Elemente der Werkzeugleiste (Collection): Buttons, Umschalter, Dropdowns, Trenner.

Collection: Die Eintraege sind vom Typ [TPPGToolItem](TPPGToolItem.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.
