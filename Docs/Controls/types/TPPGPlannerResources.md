# TPPGPlannerResources

Typ in Unit `PPG.Planner` - Basis `TOwnedCollection`

Ressourcen des Planers (Personen, Räume, Geräte). Mit GroupByResource erhält jede Ressource eine eigene Spalte.

Collection: Die Eintraege sind vom Typ [TPPGPlannerResource](TPPGPlannerResource.md). Im Designer ueber den Collection-Editor (Doppelklick auf die Eigenschaft), im Code ueber `Add`, `Items[i]`, `Count`, `Delete`, `Clear`.

## Verwendet in

[TPPGDBPlanner](../TPPGDBPlanner.md), [TPPGPlanner](../TPPGPlanner.md)
